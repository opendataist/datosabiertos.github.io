990 Data Infrastructure Project Releases Brand New Features and Tools Including Curated Data Marts and API Access to Structured Data - PR.com

GivingTuesday, in collaboration with major social sector partners, has launched a comprehensive suite of tools and assets to democratize access to IRS Form 990 data. This initiative addresses longstanding barriers to nonprofit financial transparency, such as difficult access, inconsistent coverage, and reliability issues, by providing a standardized, free platform for data consumption. By transforming these essential tax filings into an open resource, the project significantly lowers the technical threshold for researchers and practitioners to analyze organizational health and governance. The core of this effort is the 990 Data Lake, which aggregates and deduplicates millions of tax forms, serving as the foundation for new utilities like mappers, parsers, and specialized data marts. These tools enable users to extract specific information regarding missions, leadership, and grants, while API access facilitates seamless integration for developers. This infrastructure shift empowers a wide range of users, from casual donors to data scientists, to make informed decisions based on verified, structured historical data without needing deep technical expertise. This release is highly relevant to open data principles because it treats fundamental sector statistics as a public utility rather than a siloed asset. By ensuring free, unrestricted access to high-quality, machine-readable data, the project establishes a replicable model for data-driven decision-making in the nonprofit sector. It exemplifies how cross-sector collaboration can build robust data infrastructure that enhances accountability, fosters innovation, and supports sustainable growth within the social impact community.
