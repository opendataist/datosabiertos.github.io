Release 0.9.1 - RAG support in the UI and in Apps + streaming fix · helixml/helix

This update replaces traditional fine-tuning with Retrieval-Augmented Generation, offering a faster method for retrieving specific facts within the user interface. By prioritizing RAG over general learning, the platform enhances efficiency for real-time data interaction while retaining fine-tuning capabilities for broader contextual understanding. Users can now embed these AI capabilities directly into applications by referencing specific data source IDs in configuration files. This structural change allows developers to easily customize assistants with pre-processed documents or learned models, bridging the gap between raw data and interactive AI experiences without complex retraining cycles. This development is crucial for open data because it simplifies the integration of public datasets into intelligent agents. By enabling rapid, document-based querying through standardized identifiers, it lowers the barrier for accessing and utilizing open information, making structured data more immediately useful and actionable for diverse audiences and automated systems.
