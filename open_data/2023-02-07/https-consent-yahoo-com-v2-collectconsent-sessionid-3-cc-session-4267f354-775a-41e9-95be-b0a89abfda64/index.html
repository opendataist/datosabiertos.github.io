Open Data
ES EN

Open data relies on transparent, publicly accessible information. This privacy notice, however, highlights the pervasive tracking and data harvesting practices common across many platforms. It details how cookies and precise location data are collected for profiling and advertising without explicit user consent. This opacity conflicts with open data principles by obscuring how personal information is aggregated and utilized by private entities. True open data requires clear accountability regarding data usage. This text serves as a reminder of the contrast between public transparency and the hidden data economies that currently dominate digital spaces.
