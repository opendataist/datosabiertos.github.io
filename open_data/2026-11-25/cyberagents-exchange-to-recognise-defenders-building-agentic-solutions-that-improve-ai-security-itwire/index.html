CyberAgents Exchange to Recognise Defenders Building Agentic Solutions that Improve AI Security | iTWire

CyberAgents Exchange to Recognise Defenders Building Agentic Solutions that Improve AI Security | iTWire

Tenable Holdings has launched the inaugural CyberAgents Exchange Agentic Cyber Awards to recognize outstanding open-source contributions in the cybersecurity sector. This initiative highlights the growing importance of shared, transparent tools among security professionals, positioning the exchange as a vital resource for defenders building solutions in the open. By celebrating these collaborations, the program underscores how collective effort accelerates defensive capabilities across the industry. The awards specifically honor open-source AI agents, skills, and MCP servers that enhance security operations. These components are hosted on a vendor-agnostic directory where every listing includes source code and licenses, allowing practitioners to verify safety before implementation. This transparency is crucial for open data initiatives, as it ensures that security tools are auditable, reproducible, and freely accessible for improvement by the broader community. This recognition mechanism is highly relevant to open data principles because it validates the utility of publicly available technical artifacts. By promoting visibility and reuse of high-quality code, the awards encourage a culture where knowledge and tools are shared rather than hoarded. This approach not only accelerates innovation but also strengthens global cybersecurity resilience by ensuring that effective defensive strategies are widely understood and implemented by all practitioners.
