Bridgeport Mayor Joe Ganim vows to improve public records requests

The mayor reversed a seven-year pattern of delaying public records requests by decentralizing processing to relevant departments. This structural change addresses long-standing accusations of intentional suppression and understaffing that hindered transparency. The reform is crucial for open data, ensuring citizens can access information without bureaucratic obstructions, thereby restoring trust in municipal governance.
