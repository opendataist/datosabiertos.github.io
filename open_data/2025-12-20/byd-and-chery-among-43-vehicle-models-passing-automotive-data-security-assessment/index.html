BYD and Chery among 43 vehicle models passing automotive data security assessment

BYD and Chery among 43 vehicle models passing automotive data security assessment

Nine major automotive manufacturers, including BYD and Chery, have achieved China’s latest automotive data security assessment. This voluntary evaluation confirms that their models comply with stringent national regulations regarding the handling of connected vehicle data. By passing all five required criteria, these companies demonstrate a commitment to safeguarding personal and organizational information generated by modern automobiles. The assessment focuses on five key security standards: anonymizing exterior facial data, ensuring internal processing of cabin information, preventing default data collection, providing clear personal information notices, and defining precise data ranges. These measures are grounded in China’s 2021 Regulation on Automobile Data Security and specific national technical standards. Compliance requires manufacturers to process sensitive data internally, avoid transmitting personal information externally without cause, and obtain explicit user consent for data collection. This development is highly relevant to open data because it establishes a robust framework for handling vehicle-generated data. It clarifies the boundary between open data sharing and privacy protection, ensuring that while connected cars produce vast amounts of information, personal identifiers are anonymized and protected. This structure supports the responsible creation of open datasets for research and innovation, balancing transparency with strict regulatory safeguards for user privacy.
