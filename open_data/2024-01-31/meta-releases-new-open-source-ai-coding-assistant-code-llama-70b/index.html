Meta releases new open-source AI coding assistant Code Llama 70B

Meta AI introduced Code Llama 70B, its most powerful open-source coding model to date, significantly improving accuracy over previous iterations. By outperforming GPT-3.5 on standard benchmarks, it demonstrates the growing capability of open-weight architectures in complex software development tasks. The model’s availability on Hugging Face and GitHub supports the open_data movement by providing free, accessible tools for research. This transparency allows the community to inspect, utilize, and build upon robust code generation technologies without vendor lock-in. Open access to such high-performing models fosters innovation and accelerates development cycles globally. It reinforces the value of shared data and models in driving technological progress beyond proprietary boundaries.
