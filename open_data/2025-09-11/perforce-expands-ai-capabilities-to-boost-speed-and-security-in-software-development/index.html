Perforce Expands AI Capabilities to Boost Speed and Security in Software Development

Perforce Expands AI Capabilities to Boost Speed and Security in Software Development

Perforce Software has launched Delphix AI, an integrated solution designed to generate high-fidelity synthetic data for secure application delivery and development. By embedding a specialized language model directly into the DevOps Data Platform, the company addresses the growing industry challenge of managing synthetic data while maintaining strict privacy compliance. This approach allows organizations to automate data provisioning across the development lifecycle, eliminating the bottlenecks associated with legacy tools and manual processes. The core innovation lies in combining data masking with AI-driven synthetic generation, offering a unified alternative to fragmented point tools. This platform ensures that data remains referentially intact and customizable for specific industry needs, such as healthcare, without exposing sensitive information. The solution is built on Perforce Intelligence, utilizing an in-platform, air-gapped model that keeps data within the IT perimeter, thereby enabling responsible and secure AI adoption without the need for external data science resources. This release is particularly relevant to open data initiatives because it demonstrates a viable pathway for leveraging real-world data structures in AI training and analytics while fully respecting privacy constraints. By providing a mechanism to create realistic, compliant datasets from sensitive sources, it facilitates the broader goals of data utility and reproducibility without compromising individual privacy or regulatory requirements. This empowers developers to innovate at scale, ensuring that the benefits of AI can be realized safely within enterprise environments.
