Meta tiene un nuevo sistema para la configuración de Instagram y Facebook

Meta is centralizing account settings for Facebook, Instagram, and Messenger, allowing users to manage personal data, security, and advertising preferences from a single interface within each app. This consolidation simplifies the previously fragmented experience, enabling users to adjust settings across platforms seamlessly, provided they manually link their accounts. The update enhances user control by unifying configuration options, while still allowing individuals to keep accounts separate if preferred. This gradual rollout aims to reduce confusion and improve transparency regarding how personal information is handled. This development is highly relevant to open data because it empowers users with greater visibility and accessibility into their data management processes. By simplifying access to privacy and advertising controls, it supports the core open data principle of transparency, enabling individuals to better understand and exercise autonomy over their digital footprint.
