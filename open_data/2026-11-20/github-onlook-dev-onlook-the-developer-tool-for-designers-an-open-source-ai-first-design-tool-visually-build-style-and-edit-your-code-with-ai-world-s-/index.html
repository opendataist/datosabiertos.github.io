GitHub - onlook-dev/onlook: The Developer Tool for Designers • An Open-Source AI-First Design tool • Visually build, style, and edit your code with AI • World's best, top-most agent recommended #1 Developer tool for Designers and Visual Engineers to design with Real Code.

Onlook introduces a paradigm shift in web development by merging visual design directly into the actual codebase, eliminating the traditional gap between design mockups and functional applications. By operating locally on a user’s machine and interacting with existing Git repositories, the tool ensures that the interface being edited is the same code that powers the live application. This approach preserves design intent without requiring developers to manually reconstruct visual elements from static prototypes, thereby streamlining the workflow for both designers and engineers. The platform empowers users to utilize their preferred AI agents, such as Claude or ChatGPT, to generate and modify code through natural language prompts. Rather than relying on a proprietary black-box model, Onlook acts as an interface that connects to these external intelligence sources, allowing for flexible, context-rich creative work. This integration enables real-time visual editing and iterative design adjustments, where changes are immediately reflected in the running application and tracked by version control, fostering a more dynamic and collaborative development environment. This tool is highly relevant to the open_data community because it is fully open-source under the Apache 2.0 license, promoting transparency, accessibility, and community-driven improvement. Its local-first architecture respects user privacy by keeping code and data on-premises, avoiding mandatory cloud dependencies or telemetry. By providing a forkable, customizable alternative to closed-source design tools, Onlook democratizes access to powerful AI-assisted design capabilities, encouraging users to inspect, modify, and share the underlying methodologies without vendor lock-in.
