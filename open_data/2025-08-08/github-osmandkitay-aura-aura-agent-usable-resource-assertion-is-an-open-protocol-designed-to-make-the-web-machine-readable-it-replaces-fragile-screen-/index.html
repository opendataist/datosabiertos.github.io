GitHub - osmandkitay/aura: AURA (Agent-Usable Resource Assertion) is an open protocol designed to make the web machine-readable. It replaces fragile screen scraping with a declarative aura.json manifest, allowing websites to expose their capabilities as a secure, efficient, and standardized API for AI agents.

AURA introduces a standardized protocol that enables AI agents to interact with web services through explicit, machine-readable contracts rather than brittle user interface scraping. By defining a manifest of available capabilities and their corresponding HTTP actions, the system allows agents to execute tasks with precision and reliability. This shift from implicit UI interpretation to explicit declaration reduces errors and enhances the stability of automated interactions with web applications. The architecture emphasizes security and control by treating the manifest as a descriptive guide rather than a permission grant. While the manifest outlines available actions, the server retains ultimate authority, enforcing authentication, authorization, and input validation for every request. This ensures that the open declaration of capabilities does not compromise security, as every action remains subject to strict server-side checks and auditability, preventing unauthorized or unsafe operations. This approach is highly relevant to the open data movement as it bridges the gap between static data access and dynamic, actionable service integration. It provides a structured method for exposing functional capabilities to autonomous agents, fostering a more interoperable and intelligent web ecosystem. By standardizing how agents discover and execute actions, AURA supports the evolution of the web into a more programmable and agent-friendly infrastructure.
