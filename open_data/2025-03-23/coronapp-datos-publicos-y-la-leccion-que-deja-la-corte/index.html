CoronApp: datos públicos y la lección que deja la Corte

CoronApp: datos públicos y la lección que deja la Corte

The Constitutional Court ruled that public entities must release the source code of CoronApp, reaffirming that the Public Information Access Law applies comprehensively to state digital technologies. The ruling emphasizes that transparency is essential for citizen scrutiny, dispelling the national security and intellectual property excuses often used to conceal the operation of essential public tools. The principle that security through opacity is a poor practice underlies this decision, demonstrating that publishing the source code, far from creating risks, strengthens the ability to detect vulnerabilities through public scrutiny. The official argument about the danger of hacking is revealed to be unfounded when personal data have already been removed, clearly separating public information from the handling of sensitive data, which must be protected by specific regulations, not by restricting access to the software architecture. For the open data field, this precedent is crucial because it validates access to public technical information as a mechanism for democratic control and institutional trust. Beyond the hype surrounding "algorithmic transparency," the ruling establishes a solid legal framework for auditing state technology, requiring institutions to adopt good data governance practices and accountability. This ensures that citizens can verify the suitability, fairness, and security of technological solutions implemented by the State, prioritizing fundamental rights over administrative discretion.
