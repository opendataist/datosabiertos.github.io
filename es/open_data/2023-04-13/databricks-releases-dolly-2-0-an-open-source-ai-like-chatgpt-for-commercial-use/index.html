Databricks releases Dolly 2.0, an open-source AI like ChatGPT for commercial use

Databricks ha lanzado Dolly 2.0, un modelo de lenguaje grande de código abierto diseñado para democratizar el acceso a la inteligencia artificial generativa. A diferencia de muchos sistemas propietarios, que están detrás de muros de pago o restringidos por licencias restrictivas, Dolly 2.0 es completamente de código abierto para uso comercial. Este enfoque permite a las empresas ejecutar el modelo en servidores internos, manteniendo los datos sensibles en privado y habilitando a las organizaciones a personalizar y monetizar la tecnología sin depender de proveedores externos. El desarrollo de Dolly 2.0 aborda específicamente las barreras legales enfrentadas por modelos abiertos anteriores como Alpaca, que fueron entrenados con datos obtenidos de APIs cerradas y, por lo tanto, prohibidos para aplicaciones comerciales. Para garantizar una libertad total de uso, Databricks entrenó esta versión utilizando un conjunto de datos de alta calidad recopilado de sus propios empleados. Este método único de entrenamiento elimina ambigüedades legales, ofreciendo a las empresas una alternativa conforme que admite ajustes con conjuntos de datos propietarios y desarrollo independiente. Este lanzamiento es altamente relevante para el movimiento de datos abiertos, ya que demuestra una ruta viable hacia una inteligencia artificial de código abierto sostenible y amigable para el comercio. Al proporcionar tanto los pesos del modelo como el conjunto de datos subyacente bajo licencias permisivas, Databricks fomenta la transparencia y la colaboración. Empodera a desarrolladores e investigadores para construir sobre trabajos existentes sin temor a infracciones de propiedad intelectual, promoviendo un ecosistema donde la innovación es impulsada por el conocimiento compartido en lugar de silos cerrados.
