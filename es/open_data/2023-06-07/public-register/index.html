Public register

El Banco Europeo de Inversiones prioriza la apertura para fortalecer la credibilidad, la rendición de cuentas y la sostenibilidad operativa. Al mantener un registro público de información ambiental, la institución cumple con las exigencias de transparencia de la Unión Europea y mejora las relaciones con las partes interesadas. Este compromiso destaca el papel fundamental de los datos institucionales accesibles para fomentar la confianza y una gobernanza eficaz dentro del ecosistema de datos abiertos.
