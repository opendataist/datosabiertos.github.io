MeitY presenta el manual de DEPA para facilitar el intercambio confiable de datos para el entrenamiento de IA

MeitY presenta el manual de DEPA para facilitar el intercambio confiable de datos para el entrenamiento de IA

El Ministerio de Tecnología de la Información (MeitY) de India lanzó un manual sobre el Acuerdo de Asociación Digital (DEPA) para la formación de inteligencia artificial, estableciendo un marco técnico-legal que permite una colaboración segura de datos. Al permitir que los modelos se desplacen hacia los datos en lugar de extraerlos, el sistema preserva el control institucional y la privacidad, al tiempo que garantiza una trazabilidad y responsabilidad completas. Este enfoque mitiga las preocupaciones relacionadas con la confidencialidad y la propiedad intelectual, que a menudo obstaculizan el intercambio de datos. Facilita la cooperación entre múltiples partes y transfronteriza, alineando las ambiciones de India en el ámbito de la IA con el uso responsable de los datos y apoyando la diplomacia científica global a través de estructuras innovadoras de gobernanza. Para los datos abiertos, esto representa un cambio hacia la interoperabilidad que preserva la privacidad. Demuestra cómo las arquitecturas estandarizadas pueden desbloquear conjuntos de datos valiosos para el beneficio público sin comprometer la seguridad, sentando un precedente para el intercambio ético de datos en el desarrollo de la inteligencia artificial a nivel mundial.
