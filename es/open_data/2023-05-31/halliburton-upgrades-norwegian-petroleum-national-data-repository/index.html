Halliburton upgrades Norwegian Petroleum national data repository

La Dirección Noruega de Petróleo ha lanzado Diskos 2.0, el primer Repositorio Nacional de Datos de la industria completamente nativo de la nube. Esta actualización integra automatización avanzada e inteligencia artificial para gestionar grandes volúmenes de datos de manera eficiente, reduciendo significativamente los costos de almacenamiento y mejorando la escalabilidad y la capacidad de procesamiento para obtener información sobre exploración y producción. Una innovación clave es la capacidad de acceder a datos sísmicos y de pozos completos directamente dentro de entornos de software de terceros, sin necesidad de mover o copiar los datos desde el repositorio. Esta conectividad fluida agiliza el análisis, permitiendo que los operadores y las partes interesadas realicen interpretaciones complejas al instante dentro de un entorno de gestión transparente y limpio. Este desarrollo es altamente relevante para los principios de datos abiertos, ya que demuestra cómo las arquitecturas nativas de la nube pueden facilitar el intercambio y el acceso a datos de forma segura y sin fricciones. Al eliminar las barreras tradicionales para la recuperación de datos y permitir su uso analítico inmediato, el sistema promueve una mayor transparencia y eficiencia en el sector energético, estableciendo un precedente para ecosistemas de datos abiertos y accesibles.
