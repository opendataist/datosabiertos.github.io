Do it via UIDAI: States shouldn’t create separate biometric databases. Multiple datasets increase security risk.

El artículo sostiene que, aunque los gobiernos buscan prevenir el fraude al exigir la recopilación de datos biométricos para los servicios locales, esta práctica fragmenta peligrosamente la seguridad de los datos. La ampliación de los puntos de recopilación crea múltiples objetivos vulnerables, lo que incrementa el riesgo de brechas a gran escala que comprometen todo el ecosistema nacional de identidad, en lugar de afectar únicamente a bases de datos locales aisladas. Centralizar el almacenamiento biométrico bajo una autoridad única es esencial para minimizar la exposición. Dado que ningún sistema es completamente seguro frente a hackers determinados, concentrar los datos reduce las superficies de ataque potenciales. Las entidades locales deberían autenticar las identidades en tiempo real mediante APIs seguras, en lugar de almacenar ellas mismas las características biométricas sensibles, aprovechando así la infraestructura nacional sin asumir responsabilidades de seguridad innecesarias. Esta perspectiva es fundamental para los defensores de los datos abiertos, ya que pone de manifiesto la tensión entre accesibilidad y privacidad. Subraya que una infraestructura eficiente de datos abiertos debe priorizar arquitecturas de seguridad robustas y centralizadas para proteger los derechos fundamentales de los ciudadanos. Al restringir la recopilación de datos, los responsables políticos pueden equilibrar las necesidades legítimas de verificación con la imperativa necesidad de salvaguardar la información personal frente a vulnerabilidades sistémicas.
