Hacienda retrasa un año la entrada en vigor de Verifactu, el nuevo sistema de facturación para pymes y autónomos

Hacienda retrasa un año la entrada en vigor de Verifactu, el nuevo sistema de facturación para pymes y autónomos

El gobierno español está posponiendo un año la implementación obligatoria de Verifactu para dar a las empresas y profesionales más tiempo para adaptar su software de contabilidad. Esta prórroga garantiza que los nuevos sistemas de verificación digital de facturas, que requieren registros seguros e inmutables accesibles para las autoridades fiscales, solo se aplicarán a partir de 2027. Este ajuste pone de manifiesto la tensión continua entre el cumplimiento normativo y la viabilidad técnica para las pequeñas empresas. Al aligerar la carga inmediata, las autoridades buscan evitar disrupciones mientras mantienen estrictos mecanismos de supervisión para la transparencia financiera y el control fiscal. Este desarrollo es relevante para los datos abiertos, ya que subraya la intersección crítica entre la transparencia fiscal pública y la infraestructura tecnológica privada. La obligación de crear registros a prueba de manipulaciones y accesibles demuestra cómo la política gubernamental impulsa la adopción de estándares de datos que, con el tiempo, facilitan una mayor interoperabilidad y el acceso público a información económica verificada.
