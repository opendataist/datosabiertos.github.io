Atenciones residentes extranjeros: abrieron las inscripciones para el padrón municipal

La junta electoral municipal abrió el registro para residentes extranjeros, destacando que el empadronamiento electoral es un documento público que acredita la residencia habitual. Los solicitantes deben validar su dirección mediante recibos de servicios públicos o una declaración jurada. Este proceso garantiza datos transparentes y accesibles para la participación democrática local.
