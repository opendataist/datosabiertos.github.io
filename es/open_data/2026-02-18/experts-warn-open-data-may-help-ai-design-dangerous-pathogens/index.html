Experts warn open data may help AI design dangerous pathogens

Investigadores destacados sostienen que, si bien los datos biológicos abiertos impulsan el progreso científico, el acceso sin restricciones a conjuntos específicos de datos de patógenos genera graves riesgos para la bioseguridad en la era de la inteligencia artificial avanzada. Estos modelos pueden predecir mutaciones y diseñar patógenos mejorados, lo que podría acelerar la creación de amenazas biológicas. La conclusión fundamental es que debe alcanzarse un equilibrio: mantener la apertura para la investigación general, mientras se implementan salvaguardas rigurosas para los datos de alto riesgo, con el fin de prevenir su uso indebido por parte de actores malintencionados. Para abordar esta brecha, los autores proponen un nuevo marco de gobernanza que clasifica los datos biológicos en niveles según su riesgo para la bioseguridad. Este sistema por niveles permite que la información biológica cotidiana siga siendo de acceso libre, mientras se aplican controles estrictos a los datos que podrían facilitar el diseño de virus peligrosos. Al definir qué conjuntos de datos representan riesgos significativos antes de que estén ampliamente disponibles para los desarrolladores de IA, este enfoque busca prevenir el desarrollo accidental o intencional de armas biológicas mediante herramientas de IA de código abierto. Este artículo es altamente relevante para las comunidades de datos abiertos, ya que cuestiona la suposición de que todos los datos científicos deben ser universal e incondicionalmente abiertos. Destaca la necesidad crítica de una gobernanza de datos matizada, introduciendo conceptos como la marca de agua y la biometría conductual para verificar a los usuarios legítimos. La propuesta insta a la comunidad a adoptar reglas coherentes respaldadas por expertos para la información sensible, demostrando que las prácticas responsables de datos abiertos deben evolucionar para incluir medidas de seguridad robustas junto con la transparencia.
