Perforce expands AI capabilities to boost speed and security in software development - CIE

Perforce expands AI capabilities to boost speed and security in software development - CIE

Perforce ha presentado Delphix AI, un modelo de inteligencia artificial integrado dentro de su Plataforma de Datos para DevOps, diseñado para generar datos sintéticos de alta fidelidad. Esta innovación permite que los equipos de desarrollo y pruebas creen automáticamente conjuntos de datos realistas y conformes, sin depender de información sensible de producción. Al integrar esta capacidad directamente en la plataforma, las organizaciones pueden optimizar sus pipelines de entrega de software, garantizando que los entornos de pruebas permanezcan seguros y alineados con las normativas de privacidad, al tiempo que mantienen la integridad de los datos para una validación precisa de las aplicaciones. La solución aborda las crecientes preocupaciones de la industria respecto a la gobernanza y gestión de los datos sintéticos, un desafío que Gartner prevé que se convertirá en crítico para muchos líderes empresariales. A diferencia de las herramientas tradicionales de enmascaramiento, que solo protegen los datos existentes, los datos sintéticos generados por IA crean nuevos escenarios seguros para pruebas y análisis. Esta distinción es particularmente vital para industrias reguladas como la salud, donde las organizaciones deben equilibrar la necesidad de una innovación sólida con estrictas obligaciones de privacidad, permitiendo un desarrollo más seguro sin comprometer la velocidad ni el cumplimiento normativo. Este lanzamiento es altamente relevante para la comunidad open_data, ya que demuestra cómo los sistemas cerrados de grado empresarial pueden utilizar la IA de manera responsable para generar datos que imitan las distribuciones del mundo real sin exponer información privada. Destaca un enfoque práctico para la utilidad de los datos, donde la generación sintética apoya las necesidades de investigación y pruebas respetando la soberanía de los datos. Al mantener el modelo de IA aislado (air-gapped) y operando dentro del perímetro de TI, Perforce muestra cómo las organizaciones pueden adoptar técnicas avanzadas de gestión de datos que priorizan la seguridad y el uso ético de la IA, estableciendo un precedente para prácticas seguras de datos en la ingeniería de software moderna.
