Meta releases AI model that can identify items within images

Meta ha lanzado el Modelo Segment Anything, una IA revolucionaria capaz de identificar objetos en imágenes sin necesidad de un entrenamiento específico previo. Esta capacidad permite seleccionar con precisión los objetos mediante simples indicaciones textuales o clics, lo que demuestra un avance significativo en la tecnología de reconocimiento visual. El lanzamiento coincide con la intensificación de la competencia entre las grandes empresas tecnológicas para dominar el panorama de la inteligencia artificial. Mientras Meta planea integrar herramientas de IA generativa en sus plataformas, este nuevo modelo se centra en tareas fundamentales de identificación, con el objetivo de ampliar el acceso a capacidades avanzadas de procesamiento visual que anteriormente solo se utilizaban internamente para sistemas de moderación y recomendación. Este lanzamiento es relevante para los datos abiertos porque proporciona el conjunto de datos de imágenes anotadas más grande jamás creado, junto con el modelo. Al poner estos recursos a disposición bajo una licencia no comercial, Meta facilita una investigación y desarrollo más amplios, permitiendo que la comunidad global experimente y mejore las tecnologías de comprensión visual de última generación.
