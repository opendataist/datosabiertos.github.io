Apple’s new LLM Ferret is surprisingly open-source

Apple’s new LLM Ferret is surprisingly open-source

El lanzamiento por parte de Apple del modelo de código abierto Ferret marca un cambio significativo, demostrando que las grandes empresas tecnológicas están contribuyendo cada vez más herramientas de inteligencia artificial multimodal sofisticadas al dominio público. Este movimiento desafía la reputación tradicionalmente reservada de Apple y amplía los recursos disponibles para la investigación en razonamiento visual avanzado. La capacidad del modelo de vincular las respuestas a regiones específicas de una imagen mejora la forma en que las máquinas comprenden el contexto visual. Al permitir una inferencia eficiente en dispositivos móviles, muestra aplicaciones prácticas para integrar inteligencia artificial potente directamente en el hardware personal, beneficiando tanto a usuarios como a desarrolladores. Esta contribución es vital para la comunidad de código abierto, ya que proporciona acceso transparente a los pesos y al código. Estos recursos permiten la verificación independiente y fomentan la innovación, promoviendo un ecosistema más colaborativo y transparente para el desarrollo de sistemas inteligentes de próxima generación.
