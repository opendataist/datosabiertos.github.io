New algorithms enable efficient machine learning with symmetric data

New algorithms enable efficient machine learning with symmetric data

Los investigadores han desarrollado el primer método computacionalmente eficiente para entrenar modelos de aprendizaje automático que garantizan el respeto a la simetría. Este avance aborda un desafío fundamental: los modelos podrían tratar incorrectamente los datos transformados simétricamente, como una molécula rotada, como instancias completamente nuevas. Al asegurar que los modelos comprendan inherentemente estas invariantes estructurales, las predicciones se vuelven significativamente más precisas y robustas, especialmente en campos como el descubrimiento de fármacos, donde la orientación espacial es crítica. El estudio establece que es posible equilibrar las demandas estadísticas y computacionales combinando principios algebraicos y geométricos en un nuevo algoritmo de optimización. Este enfoque reduce drásticamente la cantidad de datos de entrenamiento necesarios en comparación con métodos tradicionales como la augmentación de datos, mientras mantiene la eficiencia teórica. Los hallazgos proporcionan un marco claro para diseñar redes neuronales que no solo tengan un mejor desempeño, sino que también ofrezcan mayor interpretabilidad sobre cómo procesan la información simétrica. Esta investigación es altamente relevante para el movimiento de datos abiertos, ya que mejora la utilidad de los conjuntos de datos científicos públicamente disponibles. Cuando los modelos pueden aprender con precisión a partir de datos simétricos sin requerir recursos computacionales excesivos ni una duplicación masiva de datos, los conjuntos de datos abiertos en química y física se vuelven más valiosos para la investigación colaborativa. Esto permite a la comunidad construir herramientas más potentes y eficientes en recursos, aprovechando los datos abiertos existentes para resolver problemas complejos en la ciencia de materiales y la modelización climática.
