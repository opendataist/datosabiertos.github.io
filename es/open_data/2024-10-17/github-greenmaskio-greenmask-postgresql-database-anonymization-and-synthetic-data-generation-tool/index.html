GitHub - GreenmaskIO/greenmask: PostgreSQL database anonymization and synthetic data generation tool

Greenmask permite una gestión lógica y segura de bases de datos al integrar la anonimización y la generación de datos sintéticos directamente en los flujos de trabajo de copia de seguridad. Este enfoque garantiza que la información sensible se enmascare de manera consistente mientras se mantiene la integridad referencial, permitiendo a los equipos crear de forma segura subconjuntos de desarrollo más pequeños y realistas. Al reemplazar las herramientas estándar de volcado de datos, simplifica el cumplimiento normativo y la seguridad en entornos de staging. Las transformaciones deterministas de la herramienta y su soporte flexible de almacenamiento aseguran que los datos permanezcan lógicos y accesibles en diversas plataformas sin comprometer la estructura de la base de datos. Esta utilidad es fundamental para las iniciativas de datos abiertos, ya que facilita el uso y la compartición seguros de conjuntos de datos similares a los de producción. Al proporcionar mecanismos robustos para la preparación de datos que preservan la privacidad, permite a los desarrolladores construir sistemas confiables sin exponer información sensible en bruto.
