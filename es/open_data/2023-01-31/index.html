Datos que transforman: 8 casos de transparencia y poder ciudadano

El acceso a datos abiertos ofrece ventajas claras para las usuarias. La transparencia permite verificar la calidad de los servicios públicos. También permite exigir responsabilidades. Los estudios demuestran que la disponibilidad de información reduce la asimetría de poder entre instituciones y ciudadanos. Sin embargo, el uso de datos abiertos presenta desafíos significativos. La sobrecarga de información puede generar confusión. Falta contexto o educación digital. Los estudios indican que la falta de alfabetización en datos limita la capacidad de las usuarias. No pueden aprovechar estas herramientas. La complejidad técnica, abordada en Cómo usar la API de un portal de datos abiertos: CKAN y DCAT, puede excluir a quienes no tienen recursos o tiempo para aprender.
