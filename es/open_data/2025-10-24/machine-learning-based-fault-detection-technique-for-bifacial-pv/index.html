Machine learning-based fault detection technique for bifacial PV

Machine learning-based fault detection technique for bifacial PV

Los investigadores han desarrollado un marco robusto de aprendizaje automático para la detección de fallos en sistemas fotovoltaicos bifaciales, abordando una brecha crítica en el mantenimiento de las energías renovables. Al integrar una red neuronal convolucional unidimensional con un clasificador de bosques aleatorios, el estudio establece una herramienta poderosa para identificar problemas específicos, como la acumulación de polvo, la sombra, el envejecimiento y las grietas físicas. Este enfoque híbrido supera significativamente a los modelos independientes, logrando una precisión casi perfecta al distinguir los estados operativos generales y una alta precisión al identificar tipos individuales de fallos. El estudio destaca la resiliencia única de la tecnología bifacial, demostrando que estos sistemas pueden mantener una salida de energía superior incluso bajo condiciones severas de sombra o fallos. El modelo desarrollado aprovecha el análisis de las curvas corriente-voltaje para detectar anomalías con un mínimo de falsos positivos, garantizando diagnósticos confiables. Esta capacidad es esencial para maximizar la eficiencia y la longevidad de las instalaciones solares, ya que la detección temprana y precisa de fallos previene pérdidas significativas de energía y reduce las costosas inspecciones manuales. Esta investigación es altamente relevante para las iniciativas de datos abiertos, ya que avanza en la automatización del monitoreo solar mediante métodos computacionales sofisticados y replicables. Al proporcionar un marco validado para la clasificación de fallos, fomenta el intercambio de conjuntos de datos estandarizados y algoritmos dentro de la comunidad científica. Esta transparencia promueve la innovación colaborativa, permitiendo que otros investigadores construyan sobre estos modelos para crear soluciones más accesibles y basadas en datos para la gestión de la infraestructura global de energías renovables.
