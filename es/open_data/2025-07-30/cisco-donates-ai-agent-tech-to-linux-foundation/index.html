Cisco donates AI agent tech to Linux Foundation

Cisco donates AI agent tech to Linux Foundation

Cisco traslada su iniciativa de gestión de agentes de IA a la Linux Foundation, fomentando la colaboración abierta entre los principales proveedores tecnológicos. Este movimiento establece protocolos estándar de la industria que permiten a los agentes de IA descubrir, comunicarse y colaborar de manera fluida entre diversas plataformas y organizaciones. Este cambio es fundamental para open_data, ya que promueve la interoperabilidad y estándares transparentes para el intercambio de datos entre sistemas autónomos.
