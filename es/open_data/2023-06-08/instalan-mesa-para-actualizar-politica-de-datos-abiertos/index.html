Instalan mesa para actualizar Política de Datos Abiertos

Guatemala actualizará su Política Nacional de Datos Abiertos para fortalecer la transparencia y la auditoría social. Este proceso participativo busca que los ciudadanos comprendan el uso presupuestario estatal y los beneficios públicos, involucrando a sectores gubernamentales, privados y la sociedad civil. Los datos abiertos se consideran esenciales para fortalecer la democracia, la gobernabilidad y la lucha contra la corrupción. Además, constituyen una fuente inestimable para impulsar la innovación y mejorar la capacidad institucional mediante herramientas digitales. Este enfoque es relevante para el movimiento de datos abiertos global al demostrar cómo la transparencia gubernamental empodera a la ciudadanía. Al priorizar la inclusión y el diálogo, se establece un modelo para convertir la información pública en un mecanismo concreto de rendición de cuentas y desarrollo social.
