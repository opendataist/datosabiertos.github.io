Datos Abiertos (Open data)
ES EN

El proyecto RedPajama aborda un desequilibrio crítico en la inteligencia artificial al ofrecer una alternativa completamente de código abierto a potentes modelos base comerciales restringidos. Al reproducir el conjunto de datos de entrenamiento de los principales modelos LLaMA, esta iniciativa tiene como objetivo eliminar las barreras para la investigación, la personalización y el despliegue seguro con datos sensibles. Este esfuerzo representa un momento pivotal tipo "Linux" para la IA, demostrando que la comunidad de código abierto puede alcanzar la paridad con las ofertas comerciales cerradas, fomentando así una creatividad y transparencia más amplias. Central a este logro es la publicación de un conjunto de datos de preentrenamiento reproducible y de alta calidad, que comprende más de un billón de tokens. El proyecto garantiza que cualquier persona pueda seguir exactamente la receta de preparación de datos y los filtros de calidad utilizados por Meta, abarcando fuentes diversas como rastreadores web, artículos científicos, repositorios de código y libros. Esta transparencia permite a la comunidad comprender y confiar en la canalización de datos, asegurando que los modelos resultantes se construyan sobre una base de integridad verificable en lugar de métodos opacos y propietarios. Este desarrollo es altamente relevante para el movimiento de datos abiertos porque prioriza la accesibilidad y la reutilización del material fundamental necesario para la IA avanzada. Al hacer públicos el conjunto de datos y la lógica de procesamiento, RedPajama empodera a investigadores y desarrolladores para construir sobre un recurso compartido sin restricciones legales o técnicas. Establece un precedente para la innovación colaborativa, demostrando que los ecosistemas de datos abiertos pueden sostener el desarrollo de modelos de última generación, democratizando finalmente el acceso a la tecnología de vanguardia.
