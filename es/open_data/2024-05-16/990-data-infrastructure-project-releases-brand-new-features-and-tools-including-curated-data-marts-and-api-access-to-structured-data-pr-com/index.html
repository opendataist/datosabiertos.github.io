990 Data Infrastructure Project Releases Brand New Features and Tools Including Curated Data Marts and API Access to Structured Data - PR.com

GivingTuesday, en colaboración con importantes socios del sector social, ha lanzado un conjunto integral de herramientas y recursos para democratizar el acceso a los datos del Formulario 990 del IRS. Esta iniciativa aborda las barreras de larga data a la transparencia financiera de las organizaciones sin fines de lucro, como el acceso difícil, la cobertura inconsistente y los problemas de confiabilidad, al proporcionar una plataforma estandarizada y gratuita para el consumo de datos. Al transformar estos documentos fiscales esenciales en un recurso abierto, el proyecto reduce significativamente la barrera técnica para que investigadores y profesionales analicen la salud organizacional y la gobernanza. El núcleo de este esfuerzo es el Lago de Datos 990, que agrega y deduplica millones de formularios fiscales, sirviendo como base para nuevas utilidades como mapeadores, analizadores sintácticos (parsers) y almacenes de datos especializados. Estas herramientas permiten a los usuarios extraer información específica sobre misiones, liderazgo y subvenciones, mientras que el acceso a la API facilita la integración fluida para desarrolladores. Este cambio en la infraestructura empodera a una amplia gama de usuarios, desde donantes casuales hasta científicos de datos, para tomar decisiones informadas basadas en datos históricos verificados y estructurados sin necesidad de conocimientos técnicos profundos. Este lanzamiento es altamente relevante para los principios de datos abiertos porque trata las estadísticas fundamentales del sector como un servicio público en lugar de un activo aislado. Al garantizar el acceso gratuito e ilimitado a datos de alta calidad y legibles por máquina, el proyecto establece un modelo replicable para la toma de decisiones basada en datos en el sector sin fines de lucro. Ejemplifica cómo la colaboración intersectorial puede construir una infraestructura de datos robusta que mejore la rendición de cuentas, fomente la innovación y apoye el crecimiento sostenible dentro de la comunidad de impacto social.
