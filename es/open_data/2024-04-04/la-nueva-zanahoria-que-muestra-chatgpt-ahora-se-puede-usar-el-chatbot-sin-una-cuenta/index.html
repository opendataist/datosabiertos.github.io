La nueva zanahoria que muestra ChatGPT: ahora se puede usar el chatbot sin una cuenta

OpenAI ha eliminado la obligatoriedad de crear una cuenta para acceder a la versión gratuita de ChatGPT, utilizando el modelo GPT-3.5. Esta decisión busca democratizar el acceso a la inteligencia artificial generativa, permitiendo que cualquier persona experimente sus beneficios sin barreras de registro iniciales, manteniendo las credenciales únicamente para funciones premium o de seguridad reforzada. La implementación incluye restricciones adicionales para usuarios anónimos, como límites en la generación de imágenes y bloqueos más estrictos, diseñados por equipos especializados para mitigar el abuso. Estos protocolos aseguran que la apertura del acceso no comprometa la seguridad de la plataforma, mientras se recopilan datos valiosos para el entrenamiento continuo del sistema, entendiendo que el volumen de interacciones es fundamental para mejorar la herramienta. Este cambio es relevante para open_data porque ilustra cómo las grandes corporaciones tecnológicas gestionan el acceso a sus herramientas: ofrecen muestras gratuitas para acumular datos masivos que mejoran sus algoritmos, mientras mantienen la propiedad restrictiva sobre los activos más valiosos. La estrategia refleja un modelo donde la "prueba" es un medio para generar insights y datos, incentivando finalmente la conversión hacia servicios de pago, lo que plantea interrogantes éticos sobre la transparencia en el uso de datos públicos para entrenar sistemas privados.
