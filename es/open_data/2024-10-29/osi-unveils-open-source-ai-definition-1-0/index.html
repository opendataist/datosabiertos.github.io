OSI unveils Open Source AI Definition 1.0

La Iniciativa de Código Abierto (Open Source Initiative) ha lanzado la primera definición estable para la inteligencia artificial de código abierto, con el objetivo de establecer principios que faciliten una colaboración sin restricciones y simplificada. Este marco busca replicar los estándares exitosos del ecosistema de software de código abierto dentro del panorama en rápida evolución de la inteligencia artificial. Respaldado por grandes empresas tecnológicas y organizaciones globales, el estándar proporciona un punto de referencia claro para la transparencia y el desarrollo impulsado por la comunidad. Ofrece una estructura de gobernanza fundamental para los profesionales de la IA, asegurando que los ideales del código abierto se conserven a medida que la tecnología escala a nivel mundial. Este avance es crucial para los datos abiertos, ya que aclara cómo deben compartirse los pesos de los modelos, los datos de entrenamiento y las metodologías para calificar como código abierto. Establece los requisitos de transparencia necesarios para los conjuntos de datos y los algoritmos, fomentando la confianza y la interoperabilidad en el ecosistema más amplio de datos.
