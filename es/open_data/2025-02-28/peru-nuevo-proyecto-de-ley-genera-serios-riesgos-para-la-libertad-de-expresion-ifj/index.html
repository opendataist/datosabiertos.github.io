Perú: nuevo proyecto de ley genera serios riesgos para la libertad de expresión / IFJ

Perú: nuevo proyecto de ley genera serios riesgos para la libertad de expresión / IFJ

Este artículo destaca un conflicto crítico entre el objetivo declarado de transparencia en la propiedad de los medios y la amenaza real que representa un nuevo proyecto de ley peruano para la libertad de expresión. La legislación otorga al poder ejecutivo la facultad de recopilar datos e imponer sanciones severas, incluido el cierre de medios de comunicación. Esto centraliza el control y establece un precedente peligroso para la supervisión gubernamental sobre las operaciones de prensa. Las medidas propuestas corren el riesgo de transformar las iniciativas de transparencia en mecanismos de censura política y presión contra las voces críticas. Al permitir que las autoridades sancionen a los medios que cuestionan al gobierno, el proyecto de ley socava la independencia del periodismo. De hecho, legaliza la posible silenciamiento de periodistas que investigan la corrupción política o la disidencia. Para la comunidad de datos abiertos, esto constituye una advertencia clara sobre cómo la recopilación de datos puede ser utilizada como arma. La verdadera apertura requiere salvaguardas contra el uso coercitivo, asegurando que los datos sirvan para la rendición de cuentas pública y no para el control estatal. Este caso ilustra por qué la transparencia técnica debe equilibrarse con sólidas protecciones legales para las libertades civiles y la libertad de prensa, a fin de prevenir el desbordamiento autoritario.
