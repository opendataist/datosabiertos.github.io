New Privacy-Preserving Routing Method Cuts Multi-Domain Path Calculation Time by 24%, Keeps 90% Bandwidth Efficiency | Newswise

New Privacy-Preserving Routing Method Cuts Multi-Domain Path Calculation Time by 24%, Keeps 90% Bandwidth Efficiency | Newswise

Los investigadores han desarrollado BI-TE, un algoritmo novedoso que resuelve el conflicto de larga data entre la privacidad de la red y el rendimiento en entornos multi-dominio. Al integrar la privacidad diferencial con Redes Neuronales Gráficas (GNN), el sistema permite que entidades administrativas distintas colaboren en el enrutamiento del tráfico sin exponer topologías internas sensibles ni datos de ancho de banda. Esta innovación demuestra que las organizaciones pueden lograr ganancias significativas de eficiencia mientras mantienen estrictamente la confidencialidad de su información de red propietaria, rompiendo efectivamente la barrera que anteriormente dificultaba la cooperación entre dominios. El mecanismo central implica que los controladores locales añaden ruido controlado a sus informes de red antes de compartirlos, asegurando que los secretos individuales del dominio permanezcan indistinguibles para las partes externas. Un coordinador central utiliza un modelo neuronal entrenado para predecir con precisión el uso real del ancho de banda a partir de estas entradas perturbadas, permitiendo una selección de rutas casi óptima. Este enfoque elimina la necesidad de intercambiar datos en bruto, demostrando que el aprendizaje automático sofisticado puede compensar las imprecisiones introducidas por las técnicas de preservación de la privacidad, manteniendo así una alta utilización de los enlaces y una distribución justa del tráfico. Este desarrollo es altamente relevante para el movimiento de datos abiertos, ya que proporciona un marco técnico para el intercambio seguro de datos entre entidades independientes. Ilustra cómo las tecnologías que mejoran la privacidad pueden habilitar ecosistemas colaborativos sin comprometer la autonomía individual o la propiedad intelectual. Al hacer factible y segura la colaboración interdominio, BI-TE ofrece un modelo escalable para otras industrias que buscan aprovechar las perspectivas derivadas de datos colectivos mientras cumplen con estrictos estándares de confidencialidad, cerrando la brecha entre la apertura y la seguridad.
