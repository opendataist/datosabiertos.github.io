Europe and UAE plan $1 billion orbital data center with 50 connected "computers" and a central "LLM store" that allows users to select what open source model to use on data collected by satellite sensors

Europe and UAE plan $1 billion orbital data center with 50 connected "computers" and a central "LLM store" that allows users to select what open source model to use on data collected by satellite sensors

Marlan Space y Loft Orbital han asegurado una iniciativa de mil millones de dólares para ampliar su constelación de observación terrestre Altair de diez a cincuenta satélites. Esta expansión, respaldada por la inversión de los Emiratos Árabes Unidos y que utiliza los modelos de Mistral AI, tiene como objetivo cambiar el paradigma del procesamiento de datos en el espacio. Al equipar los satélites con inteligencia artificial a bordo, el sistema interpreta los datos de los sensores en órbita antes de que lleguen a la superficie, reduciendo drásticamente la latencia asociada con la transmisión tradicional de imágenes sin procesar. La arquitectura funciona como un centro de datos orbital, ofreciendo una tienda de aplicaciones centralizada donde los usuarios pueden seleccionar modelos de lenguaje específicos para procesar la información recopilada por los satélites. Este enfoque aborda el cuello de botella crítico del procesamiento de grandes volúmenes de datos de observación terrestre en la superficie. En lugar de descargar horas de grabaciones, los clientes reciben alertas inmediatas y resultados analizados, convirtiendo efectivamente la constelación en una flota de unidades de cómputo conectadas que proporcionan información casi en tiempo real para la monitorización global y la seguridad. Este desarrollo es altamente relevante para la comunidad de datos abiertos, ya que plantea preguntas fundamentales sobre la accesibilidad de los datos y la transparencia de los modelos. La tienda de aplicaciones de IA propuesta permite a los usuarios elegir sus modelos de procesamiento, pero aún no está claro si este ecosistema apoyará soluciones de código abierto o de pesos abiertos. A medida que la computación en el espacio se vuelve más centralizada, es esencial garantizar que estas plataformas no creen nuevas barreras propietarias para los datos de observación terrestre, manteniendo así los principios de apertura y acceso equitativo a la información planetaria crítica.
