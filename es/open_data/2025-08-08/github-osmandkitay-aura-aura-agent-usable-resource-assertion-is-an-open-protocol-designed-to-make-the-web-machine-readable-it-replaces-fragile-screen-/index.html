GitHub - osmandkitay/aura: AURA (Agent-Usable Resource Assertion) is an open protocol designed to make the web machine-readable. It replaces fragile screen scraping with a declarative aura.json manifest, allowing websites to expose their capabilities as a secure, efficient, and standardized API for AI agents.

AURA introduce un protocolo estandarizado que permite a los agentes de inteligencia artificial interactuar con servicios web mediante contratos explícitos y legibles por máquina, en lugar de depender de la frágil extracción de datos de la interfaz de usuario. Al definir un manifiesto de las capacidades disponibles y sus correspondientes acciones HTTP, el sistema permite a los agentes ejecutar tareas con precisión y fiabilidad. Este cambio desde la interpretación implícita de la interfaz de usuario hacia una declaración explícita reduce los errores y mejora la estabilidad de las interacciones automatizadas con aplicaciones web. La arquitectura enfatiza la seguridad y el control al tratar el manifiesto como una guía descriptiva en lugar de una concesión de permisos. Aunque el manifiesto describe las acciones disponibles, el servidor conserva la autoridad final, aplicando autenticación, autorización y validación de entradas para cada solicitud. Esto garantiza que la declaración abierta de capacidades no comprometa la seguridad, ya que cada acción está sujeta a estrictas comprobaciones del lado del servidor y a la auditoría, previniendo operaciones no autorizadas o inseguras. Este enfoque es altamente relevante para el movimiento de datos abiertos, ya que cierra la brecha entre el acceso estático a los datos y la integración dinámica de servicios accionables. Proporciona un método estructurado para exponer capacidades funcionales a agentes autónomos, fomentando un ecosistema web más interoperable e inteligente. Al estandarizar la forma en que los agentes descubren y ejecutan acciones, AURA apoya la evolución de la web hacia una infraestructura más programable y adecuada para agentes.
