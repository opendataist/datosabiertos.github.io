Microsoft soluciona un error que le daba permisos extras a Edge

Microsoft ha corregido un defecto crítico en su navegador Edge que permitía importar automáticamente la configuración y las pestañas abiertas de Chrome. Este error provocaba que, tras actualizar el sistema operativo, el navegador se abriera con datos de otros sitios web sin el consentimiento explícito del usuario, violando su privacidad y expectativas de control sobre sus propios datos. El incidente, iniciado por una observación del editor de The Verge y confirmado por numerosos usuarios, destaca la vulnerabilidad en la gestión de permisos de sincronización entre plataformas. Microsoft aclaró que, aunque la función de importación existe, el estado no se sincronizaba correctamente, mostrando una opción desactivada mientras ejecutaba una acción activa de transferencia de datos sensibles. Esta actualización es relevante para el campo de los datos abiertos y la transparencia tecnológica, ya que ilustra los riesgos cuando la interoperabilidad entre navegadores carece de salvaguardas claras. Refuerza la necesidad de que las grandes tecnológicas garanticen que la migración de datos siempre sea explícita, consciente y auditada, preservando la autonomía del usuario frente a la automatización oscura de la información personal.
