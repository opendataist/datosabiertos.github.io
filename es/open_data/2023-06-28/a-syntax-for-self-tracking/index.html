A Syntax for Self-Tracking

El autor demuestra que el auto-seguimiento efectivo y libre de contexto no requiere software propietario ni servidores centralizados. Al utilizar un formato de archivo de texto simple, las personas pueden registrar diversas métricas de vida —desde indicadores de salud hasta factores ambientales— sin quedar confinadas a categorías estrechas de aplicaciones. Este enfoque prioriza la privacidad de los datos y el control personal, permitiendo la agregación de diversos puntos de datos que podrían revelar correlaciones inesperadas, como la relación entre la temperatura del sueño y los niveles de energía del día siguiente. Para hacer este método escalable y analizable, el texto define una sintaxis flexible utilizando delimitadores específicos como dos puntos y signos de interrogación para estructurar observaciones, mediciones y pruebas A/B. Al integrar control de versiones y editores de texto, el sistema admite tanto el registro libre como la entrada estructurada de datos. Este diseño permite a los usuarios analizar retrospectivamente sus vidas, limpiando y organizando los datos brutos con el tiempo, mientras mantienen la libertad de registrar eventos de manera espontánea a medida que ocurren, en lugar de adherirse a protocolos rígidos de estudios científicos. Este artículo es altamente relevante para el movimiento open_data, ya que defiende la soberanía de los datos y la interoperabilidad. Muestra cómo los datos personales pueden permanecer bajo el control del usuario, almacenados en formatos simples y legibles que evitan el bloqueo por parte de proveedores. Al establecer un estándar ligero y legible por humanos para el auto-seguimiento, fomenta la adopción más amplia de formatos abiertos para la información personal, facilitando la portabilidad y el análisis futuros sin depender de ecosistemas cerrados o servicios en la nube opacos.
