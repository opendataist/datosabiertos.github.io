Analizan reforma para blindar INAI con suplencia

Analizan reforma para blindar INAI con suplencia

Una reforma legislativa propuesta busca garantizar que el Instituto Nacional para la Transparencia mantenga una operación continua mediante el establecimiento de un mecanismo de sustitución para cubrir las vacantes de los comisionados. Esta medida designa al secretario de mayor antigüedad para ocupar temporalmente dichos cargos, evitando vacíos operativos que podrían obstaculizar el acceso público a la información. Esta estabilidad estructural es fundamental para preservar la integridad institucional y garantizar una supervisión constante. Al evitar retrasos en los nombramientos, el sistema mantiene la rendición de cuentas y asegura que los mandatos de transparencia se cumplan sin interrupciones. Este desarrollo destaca la importancia crítica de marcos jurídicos sólidos para respaldar los ecosistemas de datos abiertos. Una gobernanza efectiva requiere una capacidad institucional ininterrumpida para proteger los derechos de los ciudadanos y promover el libre flujo de información pública, reforzando así los objetivos más amplios de transparencia y rendición de cuentas democrática.
