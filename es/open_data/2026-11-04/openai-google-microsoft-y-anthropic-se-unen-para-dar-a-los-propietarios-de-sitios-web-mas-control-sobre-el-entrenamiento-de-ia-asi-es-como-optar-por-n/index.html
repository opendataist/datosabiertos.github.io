OpenAI, Google, Microsoft y Anthropic se unen para dar a los propietarios de sitios web más control sobre el entrenamiento de IA: así es cómo optar por no participar

OpenAI, Google, Microsoft y Anthropic se unen para dar a los propietarios de sitios web más control sobre el entrenamiento de IA: así es cómo optar por no participar

Las principales empresas tecnológicas, incluidas OpenAI, Google, Microsoft y Anthropic, se han comprometido a respetar una señal estandarizada de exclusión voluntaria (opt-out) dentro de los archivos robots.txt de los sitios web. Este acuerdo permite a los propietarios de sitios prohibir explícitamente que los rastreadores de inteligencia artificial accedan a su contenido con fines de entrenamiento de modelos. Al establecer un protocolo compartido, estas empresas intentan equilibrar el insaciable apetito de datos de la inteligencia artificial con los derechos de los creadores y operadores de sitios web para controlar cómo se recopilan sus activos digitales. El artículo destaca que, aunque esta nueva norma representa un paso significativo hacia el uso ético de los datos, no constituye una solución completa. La infraestructura web actual se basa en una estrategia de "defensa en profundidad", que combina las directrices de robots.txt con otras medidas, como requisitos de inicio de sesión, limitación de direcciones IP y CAPTCHAs. Sin embargo, estos métodos adicionales suelen perjudicar la experiencia del usuario al crear fricciones para los visitantes legítimos o al no ser efectivos contra bots sofisticados que ignoran las reglas o utilizan direcciones IP rotativas, lo que deja a los propietarios de sitios web vulnerables ante la recopilación no autorizada continua de datos. Este desarrollo es altamente relevante para la comunidad de datos abiertos, ya que formaliza la tensión entre la accesibilidad de la web abierta y las necesidades de entrenamiento de la inteligencia artificial propietaria. Para investigadores y defensores de los datos abiertos, establece un precedente para la extracción de datos basada en el consentimiento, lo que podría influir en las normas futuras sobre cómo se recopila el conocimiento público. Subraya la necesidad de prácticas transparentes y respetuosas en el manejo de datos en un ecosistema donde internet actúa como el principal archivo del conocimiento humano, impulsando un cambio desde la recopilación descontrolada hacia un acceso negociado.
